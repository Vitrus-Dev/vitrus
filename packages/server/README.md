# @vitrus/server

A single-process [Vitrus](https://vitrus.dev) server: ingest, the query API, the tracker and the dashboard over one SQLite file. Usually started through [`@vitrus/cli`](https://www.npmjs.com/package/@vitrus/cli).

Part of [Vitrus](https://github.com/Vitrus-Dev/vitrus) · Apache-2.0

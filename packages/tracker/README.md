# @vitrus-dev/tracker

The [Vitrus](https://vitrus.dev) browser script: 3.0 KB gzipped, no cookies, nothing stored in the browser. `dist/v.js` is the tracker; `dist/r.js` is the opt-in session recorder (every text node and input masked by default).

Most people load it from their Vitrus server (`<script defer data-site="SITE_ID" src="https://app.vitrus.dev/v.js"></script>`); this package is for self-hosting and bundling.

Part of [Vitrus](https://github.com/Vitrus-Dev/vitrus) · Apache-2.0
